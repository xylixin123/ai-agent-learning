# 实验 1.1 进度

## 这个实验在干什么（一句话）

同一道题、同一个模型，**每次少给它一样东西**，看它的表现变成什么样。

## 全程 3 步

| 步骤 | 状态 | 做什么 | 怎么算成功 |
|---|---|---|---|
| 1. 能跑起来 | ✅ 完成（11-25） | 装依赖、填 Key、跑一次完整组 | 答案里出现 `9602895.73` |
| 2. 跑五组 | ✅ 完成（11-26） | 一条命令跑完五个组 | 拿到五份结果 |
| 3. 读结果 | ✅ 完成（11-26） | 看每组的标签，写结论 | 能说出哪组出了问题、出什么问题 |

---

## 第 1 步：能跑起来

**目标**：证明这台机器上整条链路是通的。这一步不研究任何东西。

**要做的**：

1. 装依赖
2. 准备一个模型 API Key，填进环境变量
3. 跑一次「完整组」

**怎么算成功**：终端最后给出的答案里，包含 `9602895.73`。

**卡住了先看这里**：

| 现象 | 原因 |
|---|---|
| 报 401 / 402 | Key 不对或没填 |
| 报 400 | 模型名和提供商不匹配 |
| 答案里的数字不对 | 链路是通的，但模型没做对，先看它有没有真的调用工具 |

---

## 第 2 步：跑五组

**目标**：拿到真正的实验数据。

**要做的**：运行一条命令，五个组会自动依次跑完。

**怎么算成功**：五组都有结果，缺一组都不算完成。

**要注意**：

- 有几组会跑得久（它们会反复试到上限），属正常现象
- 某一组报错时，这一组会标记为「没有结论」，而不是假装成功 —— 这是程序在防止假成功
- 这一组不要开着终端走开太久，中间可能要吃几十次 API 调用

---

## 第 3 步：读结果

**目标**：把数据变成你自己的结论。

**每组只看三件事**：

1. 它答完了吗？
2. 它答对了吗？
3. 它答案里的数字，是它真看过的，还是自己编的？

**怎么算成功**：能用自己的话，说出五组各自出了什么问题。

**必须注意的一件事**：`程序跑完了` ≠ `任务做对了`。这两件事在这个实验里经常不一致。

---

## 记录区（跑完填）

| 组 | 答完了吗 | 答对了吗 | 数字有依据吗 |
|---|---|---|---|
| 完整组 | 是（3 轮） | 是 | 是（工具给的数） |
| 无历史 | 否（5 轮撞顶） | 否 | 无数字可查 |
| 无思考过程 | 是（3 轮） | 是 | 是（工具给的数） |
| 无工具 | 是（1 轮） | 否 | 没报任何数字（拒绝作答） |
| 无工具结果 | 是（4 轮） | 否 | 没编数字（主动说明拿不到结果） |

## 实验结论

模型：`deepseek-v4-flash`　任务：四季度收入换汇求合计与均值

| 组 | 结论 |
|---|---|
| **完整组** | 3 轮、4 次工具，直接答对。基准成立 |
| **无历史** | 上下文永远只有 system + 题目（5 轮都是 2 条）；15 次调用里重复 9 次，撞到 5 轮上限，**最终没有答案** |
| **无思考过程** | 与完整组完全一致（3 轮 / 4 次 / 答对）。**没有信息损失**——被删掉的思考内容（“我要把三个币换成美元”“现在求和”）在题目和工具结果里都有 |
| **无工具** | 第 1 轮就声明“这个会话里没有可用的换汇工具”，0 次调用、没编数字。**是模型主动拒绝作答，不是程序报错** |
| **无工具结果** | 14 次上下文里堆满空结果（2→6→10→14 条），9 次调用含 3 次重复；它拿测试值（1 EUR→USD、100 USD→EUR）试探后**察觉拿不到数据，第 4 轮主动停下并说明**，没编数字 |

### 三个容易混的区别

| 别混 | 区分方法 |
|---|---|
| 程序报错 vs 模型拒绝作答 | 看 `error` 是不是 `null`（本次五组全是 `null`） |
| 撞到轮数上限 vs 主动停止 | 看 `hit_iteration_ceiling` |
| 编造数字 vs 没编造 | 看 `groundedness.verdict` 是不是 `ungrounded` |

### 与书里 Kimi 记录的差异

| | 书里（Kimi K3） | 本次（DeepSeek） |
|---|---|---|
| 无思考过程 | 答对，无退化 | 答对，无退化（一致） |
| 无工具结果 | 9 次调用、**撞到上限** | 9 次调用、**第 4 轮主动停下**（不同） |

同一套代码、同一道题，行为差别来自模型本身——说明结论依赖模型，不能当定律。
